## 📁 Struktur File

```
web_ansor/
├── index.html      # File HTML utama
├── styles.css      # File CSS untuk styling
├── script.js       # File JavaScript untuk interaksi
└── README.md       # File dokumentasi
```

## 🚀 Cara Memulai

1. Clone repository ini
2. Buka file `index.html` di browser
3. Edit konten sesuai kebutuhan

## 📝 Tutorial Edit

### Ubah Nama Universitas
Buka `index.html`, cari "Ansor University" dan ganti dengan nama universitas Anda.

### Ubah Warna
Buka `styles.css`, cari kode warna (contoh: `#667eea`) dan ganti dengan warna pilihan Anda.

### Ubah Program Studi
Buka `index.html`, cari section `#program` dan edit card-card program studi.

### Ubah Informasi Kontak
Buka `index.html`, cari section `#kontak` dan update informasi kontak Anda.
